# Optional usage analytics and feedback

Call Nina desktop usage analytics is off until you opt in during onboarding or in Settings → Data & privacy. The choice is stored on this device, separately from learner data and exports. Existing installations remain opted out until a choice is made. You can turn analytics off at any time.

When enabled, Call Nina sends an app-start event and major screen visits to Aptabase's EU service. Events contain a fixed screen name, timestamps, a temporary session identifier, app version, operating system name/version, runtime version, locale, and development/release mode. Session identifiers remain in memory and change on restart or after one hour of inactivity. No account identifier, email, lesson title, answer, conversation, audio, credential, or local file path is included. Call Nina does not sell this usage data.

Aptabase receives an IP address as part of network transmission. Its service uses a daily-changing identifier to estimate daily users; these statistics do not identify returning users across days. See [Aptabase's privacy policy](https://aptabase.com/legal/privacy) for its processing practices.

Failed analytics requests are discarded, with no persistent offline backlog. Turning analytics off stops new requests and attempts to cancel requests in progress; it cannot recall events already delivered. Analytics is optional and never required for learning or feedback.

Send feedback opens a public Tally form in your browser. This happens independently of analytics consent. The link includes the app version, operating system, interface language, and environment. Tally receives your submitted category, summary, and any optional details, attachments or reply email. Screenshots and audio files are uploaded only when you choose them. Audio must be recorded separately. Do not include credentials or private learner conversations. See [Tally's privacy policy](https://tally.so/help/privacy-policy).

Feedback is reviewed by the Call Nina maintainer in Tally and may be delivered to the maintainer by email. An optional reply address is used to follow up on the report. Call Nina does not automatically link feedback submissions to Aptabase sessions. Submitted feedback and analytics already delivered are not deleted by clearing local learner data.
